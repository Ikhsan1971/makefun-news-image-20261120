# makefun-news-image-20261120

Entry untuk make.fun: **"Sum up 20 November's world news in one image"** (news-image-20261120, hadiah $250 dalam USDC).

`main.py` adalah program Python 3.13 (standar library saja, tanpa jaringan, deterministik) yang merender `entry.png` (1024x1024 PNG, < 1 MiB) berisi berita dunia Jumat, 20 November 2026. Program dijalankan dua kali dan menulis byte yang sama keduanya.

## Cara menjalankan secara lokal

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Menulis `out/entry.png`. Tidak perlu instalasi, tidak ada jaringan, hasil byte-identik setiap run.
